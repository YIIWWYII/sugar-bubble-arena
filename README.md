# 糖泡对战

浏览器运行的多模式游戏，包含经典抢包、首领挑战、生化生存、幸存者与水面合作，支持角色养成、道具组合和局内强化。

使用 `启动游戏.cmd`，或运行 `npm ci`、`npm start`。Windows 启动脚本默认地址为 http://localhost:8787/。

代码许可证见 [LICENSE](LICENSE)，第三方素材归属与来源见 [NOTICE.md](NOTICE.md)。更换项目名称不改变原代码和素材的许可条件。

## 公网单人版

访问 [糖泡对战](https://yiiwwyii.github.io/sugar-bubble-arena/)。当前提供经典抢包、首领挑战、生化生存、幸存者四个入口，支持经典 AI 对战和各模式单人练习。海盗水手玩法已并入首领挑战，选择水域地图即可进入；两套首领规则分别保留。小镇支持本地漫游与 NPC 活动，联机大厅和聊天暂未开放。

公网版采用 GitHub Pages 托管，对局在浏览器后台线程运行，不依赖个人电脑或内网穿透。角色、装扮、资源和图鉴保存在当前浏览器；不提供账号登录和跨设备同步。可在「本地存档」导出、导入备份。清除浏览器数据、更换浏览器或访问地址前请备份；旧服务端账号存档保留在原数据库，不会自动迁移到公网版。

构建：`npm ci`、`npm run build:pages`。预览：`node tools/preview-pages.mjs`，访问终端显示的地址。`npm start` 仍启动保留的服务端版本，不是 Pages 版本。

桌面游戏画面限制宽度，手机使用左侧摇杆移动、右侧按钮放置糖泡。生化与幸存者的三选一在桌面仅接受主键盘 1、2、3，长按、鼠标、空格、回车和数字小键盘不能确认；手机先点选卡片，再点击「确认强化」。练习保留对应模式机制，不结算养成资源。

### NPC 交友

「交友」页面明确区分玩家和 NPC；当前仅开放 5 位 NPC 联系人，玩家交友暂未开放。可设置社交昵称、联系人备注及关系。好感度上限 200，朋友 / 伙伴 / 挚友分别需要 20 / 60 / 120 点；每位 NPC 每日前 5 次私聊各增加 1 点（北京时间每日重置）。NPC 使用预设台词，不是实时 AI 对话。

赠礼确认后消耗糖币或技能星，资源不足或存档写入失败不扣费。糖果小袋 15 糖币 / +5，暖茶礼盒 40 糖币 / +15，星纹纪念章 90 糖币 / +35，星光挂饰 1 技能星 / +12。达到上限后停止赠礼扣费。

关系、昵称、好感度随角色存档保存并可导出。私聊和小镇聊天保存在当前浏览器的 IndexedDB 数据库 `sugar-bubble-social` 中，刷新后可读取，不随角色存档导出，也不跨设备同步。清除站点数据会删除这些记录。聊天数据库写入失败时明确提示，不将赠礼结果误报为可重试。

## 这是什么

基于 Canvas 和 Node.js 的多人游戏。服务端处理移动、泡弹、感染、AI 与胜负判定，客户端负责渲染和输入。支持单人挑战与好友房间，各模式使用适配的地图和成长规则。

## 玩法规则

每队固定三个包子。**把对方三个包子带回自己房内即可获胜**，不要求自己的包子全都在家。限时 4 分钟。

| 机制 | 实现 |
|---|---|
| 糖泡 | 约 3 秒引爆，炸开砖块并覆盖十字范围 |
| 被困 | 被泡困住后队友可接触营救，敌人接触则击破；阵亡 10 秒后复活 |
| 背包 | 背包子时减速，且**不能放泡**；掉包后须重新拾取背回 |
| 包子房 | 四角有碰撞并挡火，中间十字通道可进出，房内也能被炸到 |
| 道具 | 提升泡数 / 威力 / 速度；叉子、香蕉皮、笑脸按 `1` / `2` / `3` 使用 |
| 爆炸判定 | 按瞬间覆盖判伤，**恰好半身不命中**；残留火焰动画不重复判伤 |

### 穿技

原版玩家社群发展出的高阶技巧：在特定时机放泡，可以穿过泡弹甚至墙体。

实现按「面向目标的短按 / 持续接近 / 助跑」建立穿泡节奏，约 **0.6 秒**时放泡，当前容错窗口为 **0.42–0.82 秒**。穿势持续时间随移动速度变化。

> 这是按玩家教程与手感反馈**放宽**的设置，**不是**声称已经逐帧复现原版判定。校准记录见 [`REFERENCES.md`](REFERENCES.md)。

## 特色功能

**角色养成与扩展地图（本地扩展）**

- 大厅点击「角色养成」：轻快步伐最高 3 级，每级初始速度 +0.25；泡泡口袋、糖泡研习各最高 2 级，每级分别提升初始泡数、威力。提升从下一局生效，阵亡后仍保留养成加成。
- 疾风步、泡泡护盾、脱困术、糖果磁场各有 3 级；每次装备一个，按 **Q** 或点击底部技能按钮使用。升级延长持续时间或缩短冷却。初始解锁疾风步。
- 完成正式对局获得糖币、技能星与经验，胜负都有基础奖励；胜利、抢包和更高 AI 难度另有加成。新档案赠送 60 糖币和 3 技能星。训练、提前退出、开局后不足 15 秒的对局不发资源。结算只发一次，客户端不能指定奖励金额。
- 新增临时道具：疾风鞋（6 秒加速）、护身泡（3 秒保护）、强力糖泡（8 秒内放出的泡弹威力 +2）、磁力糖果（8 秒吸取两格内可见增益道具）。砖块掉落；新地图还提供固定拾取点。重复拾取刷新时间，阵亡与新局清除。
- 新增 **糖果花园、港湾栈道、冰雪迷城** 三张对称抢包地图，支持 AI、单人练习和真人联机；连同原有抢包山 6、水面 11，共 5 张地图。新图为同人设计，不代表原版官方地图。

档案保存至 `.runtime/profiles.sqlite`，自动迁移并保留旧 JSON 存档。游戏内「账号与存档」支持注册、跨设备登录和恢复码重设密码；注册保留当前角色与资源。启动及每 6 小时自动备份，保留最近 28 份。使用本机作为公网服务器时，双击 `启动公网游戏.cmd`，将返回的 HTTPS 地址分享给朋友。临时地址可能变化，电脑须保持开机联网；详情见 [部署说明](DEPLOY.md)。测试服务可通过 `PROFILE_FILE` 指向独立存档。

原版角色、UI、地图和已导入的道具动画继续使用；补绘素材、查找来源见 `ASSET-AUDIT.md`。运行 `npm test` 检查逻辑，`node test/browser-expansion.mjs` 会启动独立测试服务，验证真实结算、升级、技能和地图，截图保存在工作区 `work` 目录。

**🤖 人机对战（抢包山 6）**
大厅选择抢包地图和 AI 难度后点击「人机对战」，即可开始 1 对 1 抢包。简单 / 普通 / 困难的决策间隔分别为 0.65 / 0.30 / 0.12 秒；普通档会主动拾取可见道具，困难档增加困泡追击并更频繁地寻找放泡机会。所有档位都能拆砖、避险和往返抢包，遵守碰撞与爆炸判定，不读取隐藏道具或玩家输入。AI 保持基础属性，玩家养成生效；难度尚未通过真人胜率标定。

人机房间不进入公共大厅，不接受其他玩家加入，也不能使用单人训练 MOD。结算后可再次挑战。AI 使用仓库已有的原版蓝队海王子动画；素材记录中的 `D:/333/QQtang` 是原作者本地路径，本次未取得该源目录，未额外下载角色素材。

**🎮 联机对战**
服务端权威模拟，2–8 名真人；大厅实时展示公开房间与人数，可直接加入。房主开局，双人人数相等且其余玩家准备后开始。

**🧱 穿泡穿墙**
穿入墙格后进入独立前景绘制层，留在墙内时保持置顶，回到地面恢复正常遮挡。静态障碍边缘可自动滑动，对泡弹不做自动横向吸附。

**🛠 单人训练 MOD**
按 <kbd>F2</kbd> 呼出：无限泡弹 · 无限速度 · 无限威力 · 无敌 · 穿墙 · 显示墙内道具 · 放泡秒炸 · 秒赢演示。

> 全部由**服务端强制限制为单人训练**：公开联机房间会拒绝训练指令，隐藏道具位置也不会随普通对局快照下发。

**🌊 水面 11（PVE 合作）**
1–5 人同队合作，击败海盗水手获胜。水手会寻路、放泡、投掷减速胶，并撒下笑脸陷阱；洞口可藏身，踩到香蕉皮能解除减速。详见 [`WATER11.md`](WATER11.md)。

**💬 房间聊天**
<kbd>Enter</kbd> 打开聊天，再按发送，<kbd>Esc</kbd> 收起。未进房时发到大厅，进房后仅发到当前房间。

## 快速开始

> **只想玩的话不用往下看** —— 直接用上面的在线试玩链接即可。本节是给自托管和二次开发准备的。

需要 **Node.js 24 或更高版本**。

```bash
npm ci --omit=dev --ignore-scripts
npm start
```

然后打开 <http://localhost:8787>。

## 技术实现

**服务端权威架构。** 客户端只上报输入，服务端模拟一切并下发快照。这避免了作弊，也让穿泡判定在所有客户端上完全一致 —— 对一款吃帧数的竞技游戏来说这是必须的。

| 层 | 实现 |
|---|---|
| 服务端 | Node.js 原生 `http` + [`ws`](https://github.com/websockets/ws)，单进程内存态房间 |
| 前端 | 原生 ES Module + Canvas 2D，**零框架、零构建步骤** |
| 通信 | WebSocket 增量快照，含消息频率限制、包大小限制与连接心跳 |
| 测试 | Node 内置 `node:test` + Playwright 驱动的浏览器端到端断言 |

几个值得一提的细节：

- **恒定值只发一次** —— 陷阱时长、砖块布局这类整局不变的数据只在首帧下发，客户端据此反推破泡动画进度；两边不一致会导致动画直接跳帧。
- **图集帧号即血量** —— 水手血条按原版十帧素材绘制，帧号 = 血量 − 1，锚定格点而非动画帧，走动不抖。
- **素材导入可复现** —— `tools/` 下的脚本从原版客户端数据文件解析地图、图块与角色分层，导入过程留有审计记录（[`ASSET-AUDIT.md`](ASSET-AUDIT.md)）。

## 部署

单机自托管，需要一台支持 Docker Compose 的 Linux 服务器、一个域名，以及可访问的 TCP 80/443。

```bash
cp .env.example .env     # 把 GAME_DOMAIN 改成你自己的域名
docker compose up -d --build
```

Caddy 负责自动 HTTPS 与 WebSocket 反向代理，应用端口 8787 只在容器网络内可见。详细说明见 [`DEPLOY.md`](DEPLOY.md)。

**架构约束**：大厅与房间保存在**单个服务进程内**，重启会结束现有对局。目前不做多实例扩容与跨实例房间分配。

## 已知边界

当前为持续开发中的版本，以下内容需要继续验证：

- **穿技未覆盖全部变体** —— 完整 2P、侧穿、擦墙、相邻泡/墙等条件仍在验证中。
- **未做逐帧一致性验证** —— 移动速度、碰撞范围、转向偏移需以最终版客户端录像为基准测量。
- **水面 11 的 AI 是服务端重建实现**，非移植原客户端 AI；寻路与放泡节奏尚未经过真人对战校准。
- **原版有而本项目尚未实现** —— 房间密码、踢人、翻页、显示所有房间、随机加入、独立玩家列表、地图选择、房间模式（标准/自由）。
- **网络层** —— 公网高延迟下的移动预测、重连续局与长时间压力测试仍需完成。

参考资料的参数存在版本冲突（腾讯官方说明 vs 玩家实测 vs 逆向记录），取舍理由逐条记录在 [`REFERENCES.md`](REFERENCES.md)。

### 首领挑战与生化生存（本地扩展）

大厅顶部可切换经典抢包、首领挑战、生化生存。新模式支持单人挑战或创建 1–5 人合作房间；首领与水面模式队员同队，阵亡后观战；生化模式按感染状态切换阵营。

- 首领挑战：180 秒内击败首领，生命值随人数增加；半血后加快攻击，落点先预警，再生成定时糖泡。地图为首领竞技场、冰霜要塞。
- 生化生存：开局三轮三选一强化，20 秒准备后从场内 AI 中选出母体；人类防守 180 秒，丧尸尝试感染全场。潜伏期可使用随身解毒剂，转化后继续操控丧尸。
- 空格放置糖泡，E 依次切换标准、震退、冰冻、屏障、遥控糖泡，R 引爆己方遥控糖泡。也可点击对局下方按钮切换、引爆。新糖泡仅用于这两种模式，共用泡数上限。
- 屏障持续 7 秒，可阻挡敌人和一次爆炸；震退受墙体、其他糖泡阻挡；冰冻对普通敌人持续 2.5 秒，对首领持续 1.2 秒；遥控糖泡放置 0.5 秒后可引爆，10 秒自动引爆。
- 正式对局沿用养成奖励规则，练习及过短对局不结算。当前为本地规则扩展，参数仍可通过实战调整。

验证：`npm test`；新模式浏览器与双客户端检查：`node test/browser-expedition.mjs`。


### 图鉴与角色设计

- 房间页面提供地图选择、创建房间、房间号加入及公开房间列表。
- 新档案首次进入时可编辑角色外观；也可从“角色 → 角色外观”进入。支持发色、肤色、服装配色、发型、眼型、表情、头饰、翅膀、背饰、手持装饰、脚部装饰、光环与坐骑，共 13 类部位。提供 4 套快捷搭配、随机搭配与四方向预览；旧档案自动补齐新增部位。采用像素部件组合，不改变碰撞范围或属性。保存到当前档案后，在大厅、房间和实际对局中同步显示。
- 图鉴包含当前地图、临时道具及敌人收集。符合奖励条件的正式对局结束后记录探索、拾取和击杀；在图鉴页手动领取一次性奖励。累计收集 3 项可领取风行护佑，8 项可领取净化援护。限定技能无法直接购买解锁，解锁后可正常装备及升级。
- 三档竞技 AI、首领和三类感染者使用同一角色部件系统的 7 套配方。水面 11 继续保留原版水手。外观属于原角色的派生设计，不是新增官方素材。
- 测试：`node --test test/collection-appearance.test.mjs`；`node test/browser-character.mjs`。


### 模式与地图独立选择

大厅与房间创建页先选择模式，再从该模式的可用地图中选择地形。切换模式会恢复本次访问中该模式上次选择的地图；地图不会改变模式。经典抢包 6 张、首领挑战 5 张、生化生存 6 张、水面合作 3 张；冰霜要塞同时支持首领和生化，共 19 张不同地图。创建请求单独传递 `mode` 和 `mapId`，服务端继续校验兼容关系。

### 大型地图与模式适配

- 隔离城区：41×33 格，生化模式；多出口街区、回环通路和分散补给，场内 AI 开局在可通行区域随机分布，后续通过感染改变阵营。

- 大地图保持原素材尺寸，镜头跟随当前玩家，界面固定。地形只绘制视口及周边区域。
- 模式与地图使用独立字段，选择列表只展示当前模式适用的地形。

### 生化防守与感染

- 生化地图至少 31×25 格，保留原主题、掩体和双入口防守地形；防守区不再自动净化，也不提供无敌。
- 开局有 12–24 名随机分布的 AI 人员，完成三轮人类强化后进入 20 秒准备期。母体从这些 AI 中选出；后续不凭空生成感染者。
- 接触丧尸只造成伤害与感染，不困泡。潜伏时间可选 8 / 12 / 20 秒；人类初始携带 1 支解毒剂，按 4 或点击按钮使用。潜伏到期或生命耗尽会转为丧尸，保留玩家控制。
- 每 30 秒在全地图可到达空地随机刷新一批“援助物资”，替换未拾取的上一批。所有箱子外观相同，拾取前不下发具体内容。人类可获得解毒剂、强化护盾与急救、糖芯与跑鞋、陷阱组合、额外三选一；丧尸可获得修复、狂化或额外进化。
- 双方每存活 20 秒获得 2 点强化经验；人类击杀丧尸、丧尸成功转化目标各获得 6 点。升级阈值递增，双方使用独立强化池；AI 自动选择，真实玩家手动选择。
- 丧尸可以接触感染，空格发动近身利爪，Q 短时突进。生命耗尽后 8 秒重生，仍是同一名场内人员。丧尸糖泡受击可被控制；人类接触怪物不困泡。
- 简单 / 普通 / 困难调整感染者速度与 AI 寻路反应。三选一期间暂停全局，所有在线玩家完成后继续；联机与单人使用同一套服务端规则。
- 检查：`node --test test/bio.test.mjs`、`node test/browser-bio.mjs`。

### 幸存者：无尽糖泡

- 独立模式与三张专用地图：幸存者林地、幸存者遗迹、幸存者沙原。支持 1–5 人合作。
- 移动躲避、自动糖泡攻击；保留空格放置及 E/R 战术糖泡。敌人持续增援，每 30 秒提高波次并尝试投放精英；场上最多 40 名怪物，达到上限会延后刷新。怪物生命与刷新速度随时间提高，全队阵亡时结束并按既有规则结算。
- 怪物掉落经验晶体，拾取后存活队员共同获得经验。开局及升级时三选一；战斗和计时暂停，队员全部选完后恢复。每名队员每局有两次重抽，选择由服务端验证；队员离开会解除其选择等待。
- 18 项强化包括爆破、寒霜、雷电、生存和成长。极寒碎裂需要冰霜糖衣 2 级 + 高压糖芯 2 级；雷霆回路需要连锁糖泡 2 级 + 快速装填 2 级。满足条件后进化进入选项；满级强化不再出现，基础强化全部满级后提供持续补给。所有强化只在本局生效。
- 界面显示生命、等级、经验与波次；强化选择使用小型半透明面板，保留战场背景，支持点击或数字 1/2/3。

### 分模式己方伤害

经典抢包保持原有自伤和友伤。首领、生化、水面合作、幸存者取消玩家己方糖泡伤害、己方震退和己方地面陷阱负面效果；敌方糖泡、怪物接触、感染和水手投掷陷阱仍有效。泡弹阻挡、地形破坏及合作救援保持不变。水手受到自己糖泡伤害的既有机制保留。

验证：`npm test`；`node test/browser-survivor.mjs` 覆盖单人、重抽、暂停、实战经验拾取、双客户端选择和移动端页面。


### 合作模式生命与原版道具

经典抢包规则保持不变。首领与水面保留受击困泡、叉子脱困和队友救援；超时破泡扣血，生命耗尽后本局不复活。幸存者接触怪物只扣血并获得短暂无敌，不困泡。生化接触按上面的感染规则处理。

合作模式初始生命为 5，开局携带 1 把叉子、2 个香蕉皮和 2 个笑脸。香蕉皮使怪物停顿，笑脸使其减速；原有临时强化和糖泡类型继续有效。首领与水手可被困泡，追击触发破泡增伤。

幸存者自动糖泡以实际弹道飞行，墙体阻挡，碰撞后结算寒霜、溅射和连锁。幸存者与生化共用较小的半透明三选一面板，战场仍然可见；选项只对本局生效。全局暂停时禁止继续执行战斗操作。


### 感染提示、战报与模式音乐

- 潜伏感染时显示独立倒计时（精确到 0.1 秒）、剩余进度和解毒剂操作提示；最后 3 秒变为红色。倒计时使用服务器时间，三选一暂停时同步停止。
- 所有模式在战场右上角显示最近 5 条击杀或感染转化记录，7 秒后消失。真实死亡才产生击杀记录，受伤与困泡不计作击杀。
- 生化人类基础生命为 5，普通丧尸为 32，母体为 64；进化可继续提高。丧尸基础速度至少 6.4，近身伤害为 2（母体 3），基础控制抗性 30%，每 6 秒恢复 1 点生命。进化进一步强化这些能力。
- 防守时间结束仍有人类存活，显示“人类胜利”；全体转化，显示“丧尸胜利”。结算列表标注各玩家最终阵营。
- 经典模式保留 match.ogg；首领、生化、幸存者、水面分别使用原创循环音乐“糖芯决战”“隔离警戒”“无尽跃动”“海湾巡航”。声音按钮统一控制；离开对局或结算时停止背景音乐，三选一期间降低音量。
- 音乐生成源：tools/compose-mode-music.py（仅重新制曲需要 NumPy，游戏运行无需该依赖）。配乐为本项目原创，不标为 QQ 堂官方音乐。
- 验证：npm test；node test/browser-feedback.mjs（提示与结算边界使用受控状态，音乐在真实浏览器解码播放）；node test/browser-bio.mjs（真实联机流程）。
